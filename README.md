# LlamaBox

Official Android app for on-device LLM chat.  
No cloud. No accounts. Fully private AI running directly on your phone.

- **Package:** `com.llamabox`
- **Status:** Closed beta — Google Play Store
- **Platform:** Android
- **Tech:** React Native, llama.rn, on-device inference

## About

LlamaBox is a native Android application for running large language models locally using
`llama.cpp` via `llama.rn`. Features include multimodal vision chat, model management,
persistent chat history, and GPU-accelerated inference on supported hardware.
